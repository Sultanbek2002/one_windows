# one_windows

Программа для компьютерного класса Windows: демонстрация экрана учителя, просмотр экранов учеников и удалённое управление доверенными компьютерами в локальной сети.

## Classroom v2

- Автоматическое обнаружение и переподключение без ввода IP или кодов.
- Однократное подтверждение доверия и взаимная TLS-аутентификация.
- Автозапуск ученика после входа пользователя в Windows.
- Постоянное разрешение управления доверенному учителю с возможностью приостановить доступ.
- Установочные скрипты и правила брандмауэра для частной локальной сети.

Инструкция: [Classroom/README-v2.md](Classroom/README-v2.md).

## Сборка

Нужны Windows x64 и .NET 10 SDK. Из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Classroom/build.ps1
```

Скрипт использует SDK из `Classroom/.dotnet`, если он есть, иначе установленный `dotnet` из PATH. Готовые автономные ZIP создаются в `Classroom/releases/v2`. На компьютерах класса отдельный .NET не требуется.

SDK, кэши, журналы и готовые бинарные файлы не включаются в Git.

Это прототип. Перед использованием на уроках проверьте трансляцию, управление, автозапуск и производительность на компьютерах вашего класса.
