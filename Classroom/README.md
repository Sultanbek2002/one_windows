# Класс — первый прототип для Windows

**Новая версия с автообнаружением и автозапуском:** см. [README-v2.md](README-v2.md). Используйте пакеты `releases/v2/Teacher-x64.zip` и `releases/v2/Student-x64.zip`. Инструкция ниже относится к старому протоколу v1 с кодами.

Два приложения на C# / .NET 10, работающие в одной сети. SDK нужен только на компьютере разработчика. Скрипт `build.ps1` создаёт автономные приложения x64 в `releases/Teacher` и `releases/Student`.

На этом компьютере SDK 10.0.402 установлен локально в `Classroom/.dotnet`, без изменения системного PATH. Готовые EXE уже собраны; для первого запуска повторная сборка не нужна. На компьютеры класса копируйте только соответствующий EXE из папки `releases`.

## Запуск

1. Выполните `powershell -ExecutionPolicy Bypass -File .\Classroom\build.ps1` из корня рабочей папки.
2. На компьютере учителя откройте `Teacher.exe`. Код класса уже сгенерирован; нажмите «Открыть класс».
3. Разрешите приложению входящие соединения в частной сети в диалоге брандмауэра Windows. Используется TCP 47831. Программа сама не меняет брандмауэр.
4. На компьютере ученика откройте `Student.exe`. Введите IP учителя, код класса и TLS-отпечаток из окна учителя. Сверьте отпечаток непосредственно с учителем и нажмите «Подключиться».
5. Ученик передаёт свой основной экран. Учитель выбирает имя компьютера в списке для просмотра.
6. «Показывать мой экран» передаёт основной экран учителя всем подключённым ученикам.
7. Для управления выберите ученика и нажмите «Запросить управление». Ученик подтверждает запрос. Щелчки в изображении и клавиши передаются ученику. Снятие флажка разрешения или «Отключиться / Стоп» прекращает управление. Закрытие окна также разрывает соединение.

Для проверки на одном компьютере используйте `127.0.0.1`. При передаче собственного экрана возможен эффект зеркала.

## Границы прототипа

- Передача JPEG примерно раз в 700 мс, ширина изображения 1024 пикселя; это демонстрация с низкой частотой кадров, без звука и WebRTC.
- Основной монитор; левые и правые щелчки и обычные клавиши. Перетаскивание, колесо, системные сочетания, UAC и экран входа не поддерживаются.
- Нет автоматического обнаружения, установки службы, автозапуска и установщика MSI.
- Все ученики отправляют кадры; нагрузка растёт с количеством подключений. Производительность полного класса ещё нужно измерить.
- TLS с проверкой отпечатка и случайным кодом класса. Сертификат создаётся заново при открытии класса, поэтому отпечаток нужно передавать снова.
- Настоящую передачу и управление между разными компьютерами нужно проверить в вашей сети перед использованием на уроках.

## Выполненная проверка

- Оба приложения опубликованы в Release как автономные Windows x64 EXE.
- Сетевой тест `Smoke` прошёл: реальное TLS-подключение через loopback с проверкой отпечатка, Unicode в сообщениях, пакет кадра 300 КБ, пакет отзыва управления и закрытие соединения.
- Оба EXE проверены на запуск в скрытых тестовых процессах, после чего тестовые процессы закрыты. Визуальная проверка окон и проверка реального захвата экрана, ввода и работы на двух компьютерах ещё не выполнены.

Исходники общего интерфейса находятся в `Shared/Program.cs`, сетевого протокола — в `Shared/Protocol.cs`, создания сертификата для Windows — в `Shared/ClassCertificate.cs`.
